# 🎨 Caricature Me — AI-Powered Caricature Generator

Turn any photo into a fun AI-generated caricature. Upload a photo, pick sketch or colored style, and get your custom caricature in seconds — powered by Amazon Bedrock Nova Canvas.

## 🌐 Live Demo
http://caricature-app-frontend-sadia20.s3-website-us-east-1.amazonaws.com

## ✨ How it works
1. Upload your photo
2. Choose a style — ✏️ Sketch or 🎨 Colored
3. Click **Generate Caricature**
4. Download your result

## ☁️ AWS Services Used
- **AWS Lambda** — serverless backend (Node.js 20)
- **Amazon Bedrock (Nova Canvas)** — AI caricature generation
- **Amazon API Gateway** — HTTP API endpoint
- **Amazon S3** — image storage and delivery
- **Amazon S3 (Static Hosting)** — frontend hosting

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js (AWS SDK v3)
- **AI:** Amazon Bedrock Nova Canvas via InvokeModel API
